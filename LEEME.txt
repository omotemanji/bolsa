BOLSALAB 0.5 — COMPARADOR Y DETECTOR DE OPORTUNIDADES

Qué añade:
- Detector de oportunidades ordenable por puntuación, fundamental, margen de seguridad y cobertura.
- Filtros para ver todas las acciones, acciones con al menos 45% de cobertura de datos o acciones con margen de seguridad positivo.
- Comparador ampliado con puntuación de oportunidad y cobertura de datos.
- Etiquetas prudentes: candidata para estudiar, revisar en detalle, señales mixtas, cobertura baja o datos insuficientes.

Compatibilidad:
- Mantiene las mismas claves de almacenamiento local de BolsaLab 0.4, por lo que reutiliza las acciones e históricos guardados en el mismo navegador.
- No sobrescribe la versión 0.4 ni cambia las claves API.
- Los fundamentales siguen siendo manuales; no se inventan datos ausentes.

Cómo probar sin publicar todavía:
1. Guarda/exporta una copia JSON desde BolsaLab 0.4 como respaldo.
2. Descarga y descomprime BolsaLab_0.5.zip.
3. Puedes revisar index.html, pero para conservar el mismo almacenamiento debe abrirse en el mismo origen web; una copia local o distinta URL puede usar otro almacenamiento.
4. Para publicar, sube este index.html al repositorio de prueba o reemplaza el publicado solo cuando hayas guardado una copia de seguridad.

Aviso:
Las puntuaciones son heurísticas, no recomendaciones financieras. El margen depende del valor intrínseco estimado que introduzca el usuario. La cobertura de datos se basa en los campos que participan en la puntuación fundamental.
