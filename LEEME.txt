BolsaLab 0.6 — Comparador y puntuaciones

CONTENIDO
- index.html: aplicación web completa, sin instalación.

CAMBIOS EN 0.6
- Mantiene el mismo almacenamiento local que la versión 0.5 para conservar los datos guardados en el mismo navegador.
- El comparador muestra el estado de la puntuación y los fundamentales que faltan.
- La tabla de oportunidades explica por qué no se puede puntuar una acción.
- Evita mostrar puntuaciones si la cobertura ponderada de indicadores es inferior al 35%.
- El PER puede calcularse a partir del precio y el BPA/EPS si ambos están disponibles.

IMPORTANTE
- Esta versión NO descarga automáticamente datos fundamentales. Twelve Data Basic sirve para las cotizaciones disponibles en tu plan, pero no proporciona todos los fundamentales necesarios.
- Los campos ausentes no se inventan. Cuando no hay datos suficientes, se muestra una explicación.
- Antes de sustituir archivos en GitHub, conserva una copia JSON desde BolsaLab (Exportar datos).

PUBLICAR EN GITHUB PAGES
1. Descomprime el ZIP.
2. En el repositorio de GitHub, abre la carpeta raíz.
3. Sube/reemplaza index.html por el de esta carpeta y confirma el cambio.
4. Abre https://omotemanji.github.io/bolsa/ y recarga.

La aplicación guarda datos localmente en el navegador. No borres los datos del sitio ni cambies de navegador sin exportar una copia.
