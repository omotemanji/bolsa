Cómo se calcula

La puntuación combina rentabilidad, crecimiento, deuda, liquidez y valoración. Cada variable ausente no suma ni resta. No sustituye un análisis completo ni compara automáticamente bancos con empresas industriales.

Detector de oportunidades

Ordena tus acciones guardadas según los datos que hayas introducido. No descarga automáticamente fundamentales ni predice el precio futuro.

La puntuación requiere al menos un 35% de cobertura ponderada de indicadores. Si no hay datos suficientes, se muestra qué falta. El margen de seguridad solo se calcula si introduces un valor intrínseco estimado. Una puntuación alta no equivale a una recomendación de compra.

Fundamentales SEC (empresas de EE. UU.)

Lee datos oficiales publicados por la SEC. Como la SEC no permite que GitHub Pages consulte su API directamente desde el navegador, descarga el archivo JSON y después impórtalo aquí. No necesitas una clave API ni pagar.

Para Apple, el CIK es 0000320193. Abre el archivo SEC, guárdalo en Archivos y luego impórtalo aquí.

Los ratios se calculan a partir de informes anuales y pueden ser aproximados. La deuda/patrimonio puede usar pasivo total como aproximación. El PER necesita precio actualizado; el dividendo solo se calcula si hay datos por acción compatibles. Para empresas españolas, esta fuente no garantiza cobertura.

Copias y privacidad

Los datos se guardan localmente en el navegador de este iPad/móvil. Si borras los datos del sitio o cambias de navegador, puedes perderlos. Exporta una copia JSON regularmente.

Limitaciones actuales

  • Importación de fundamentales SEC para empresas estadounidenses; el archivo oficial se descarga manualmente por la limitación CORS de la SEC. Para España e internacional, los fundamentales pueden requerir entrada manual o una fuente compatible.
  • Estados Unidos: Twelve Data (datos en tiempo real según la cobertura del plan Basic y el estado del mercado). Alternativa: Yahoo Finance si Twelve Data falla.
  • España e internacional: Yahoo Finance como fuente alternativa y Marketstack para último cierre si has guardado una clave. Marketstack gratuito tiene un límite de 100 solicitudes al mes.
  • Los datos de precio llevan etiqueta de fuente y tipo de actualización; un precio al cierre nunca se presenta como tiempo real.
  • El histórico automático y la sincronización entre dispositivos aún no están implementados.
  • El DCF avanzado y la comparación sectorial son siguientes mejoras.
